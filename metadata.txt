about=Plugin QGIS pour sous-traitants FTTH : verifie la coherence des livrables aeriens (poteaux, cables, boitiers) en croisant les shapefiles fournis avec les fichiers Excel de terrain (CAP_FT, COMAC, C6) et les exports CSV GSPOT. Contact / للتواصل : youcef.geodesien@gmail.com | contact@geodeci.xyz | https://geodeci.xyz/

    5 modules d'analyse (chaque module produit une feuille dans un rapport Excel unique) :
    - MAJ BD : import des fichiers Excel FT-BT KO, preparation des modifications a appliquer sur le shapefile des poteaux.
    - Verification CAP_FT : poteaux FT du shapefile vs fiches d'appuis CAP_FT.
    - Verification COMAC : poteaux BT, cables, boitiers, portees, schemas PCM vs fichiers COMAC.
    - GESPOT vs C6 : comparaison CSV GESPOT (exports terrain) vs Excel C6 (declarations), 11 criteres.
    - C6 vs BD : annexes C6 (Orange) vs shapefile des poteaux.

    Le sous-traitant ouvre son dossier de livrable. Le plugin detecte automatiquement les sous-dossiers (CAP FT, COMAC, BASE DE DONNEES, CSV GSPOT). L'utilisateur choisit les modules a executer. Le plugin genere un rapport Excel unifie avec un tableau de bord KPI, le detail par anomalie et un glossaire metier.

    Entrees attendues (dans le dossier de projet) :
    - Shapefiles : infra_pt_pot.shp, etude_cap_ft.shp, etude_comac.shp, cables.shp, bpe.shp (CRS Lambert93 EPSG:2154).
    - Excel CAP_FT : fichiers *FicheAppui*.xlsx fournis par le terrain.
    - Excel COMAC : fichiers *ExportComac*.xlsx.
    - Excel C6 : annexes C6 Orange au format standard.
    - CSV GSPOT : exports terrain UTF-8, separateur ';', 68 colonnes.
    - Excel FT-BT KO (optionnel) : fichier recap des poteaux a modifier.

    Sortie : un fichier Excel nomme `rapport_<SRO>_<date>.xlsx` place dans le dossier du projet.
